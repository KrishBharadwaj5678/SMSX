# 📲 SMSX

これは、PythonベースのSMSボンバーで、メッセージの自動送信がどのように動作するかを示すために作成されたプロジェクトです。このプロジェクトは、実際のシナリオにおけるリクエスト処理やレート制限などの概念を理解するのに役立ちます。

> このツールを使用して個人やサービスに嫌がらせ、スパム、攻撃を行わないでください。

## ⚙️ 機能

| 機能                  | 説明                           |
| ------------------- | ---------------------------- |
| 📨 複数のSMS送信         | SMSをまとめて高速に送信できます            |
| ⏱️ 送信間隔のカスタマイズ      | メッセージ間の遅延時間を設定できます           |
| 🔁 送信回数の設定          | 送信するメッセージ数を選択できます            |
| 🧪 StreamlitベースのGUI | Streamlitで構築された使いやすいインターフェース |
| 📊 リアルタイムステータス表示    | 送信状況をUI上でリアルタイムに確認できます       |
| 🚀 軽量かつ高速           | 最小限の依存関係で高速に動作します            |

## 🛠️ 技術スタック

| 技術               | 説明                          |
| ---------------- | --------------------------- |
| 🐍 **パイソン**    | コアとなるプログラミング言語              |
| 🎨 **Streamlit** | インタラクティブなWebアプリを構築するフレームワーク |

## 🚀 はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/SMSX.git
```

### 2️⃣ フォルダへ移動

```bash
cd SMSX
```

### 3️⃣ 依存関係のインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションの実行

```bash
streamlit run app.py
```
