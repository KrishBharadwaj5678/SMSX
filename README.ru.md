# 📲 SMSX

Это Python-проект для SMS-бомбера, созданный в демонстрационных целях, чтобы показать, как работает автоматическая отправка сообщений. Проект помогает понять такие концепции, как обработка запросов и ограничение скорости (rate limiting) в реальных сценариях.

## ⚙️ Возможности

| Возможность                      | Описание                                    |
| -------------------------------- | ------------------------------------------- |
| 📨 Отправка нескольких SMS       | Быстрая массовая отправка SMS               |
| ⏱️ Настраиваемая задержка        | Установка интервала между сообщениями       |
| 🔁 Настраиваемое количество      | Выбор количества отправляемых сообщений     |
| 🧪 GUI на Streamlit              | Удобный интерфейс на базе Streamlit         |
| 📊 Обновления в реальном времени | Отображение прогресса отправки в интерфейсе |
| 🚀 Лёгкость и скорость           | Минимальные зависимости и высокая скорость  |
