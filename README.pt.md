# 📲 SMSX

Este é um projeto Python de SMS bomber criado com fins de demonstração para mostrar como funciona o envio automatizado de mensagens. Este projeto ajuda a entender conceitos como processamento de requisições e limitação de taxa (rate limiting) em cenários reais.

## ⚙️ Funcionalidades

| Funcionalidade                    | Descrição                                   |
| --------------------------------- | ------------------------------------------- |
| 📨 Envio de múltiplos SMS         | Envia SMS em massa rapidamente              |
| ⏱️ Atraso configurável            | Define o intervalo entre as mensagens       |
| 🔁 Quantidade configurável        | Escolhe quantas mensagens serão enviadas    |
| 🧪 Interface baseada em Streamlit | Interface amigável construída com Streamlit |
| 📊 Atualizações em tempo real     | Mostra o progresso do envio em tempo real   |
| 🚀 Leve e rápido                  | Poucas dependências e execução rápida       |

## 🛠️ Tecnologias Utilizadas

| Tecnologia       | Descrição                                           |
| ---------------- | --------------------------------------------------- |
| 🐍 **Pitão**    | Linguagem principal de programação                  |
| 🎨 **Streamlit** | Framework para criação de apps web interativos      |
| 🌐 **urllib**    | Gerenciamento de requisições HTTP para envio de SMS |
